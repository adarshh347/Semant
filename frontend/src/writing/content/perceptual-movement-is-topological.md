# Perceptual Movement Is Topological

To speak of agents moving inside images usually summons one technical picture: reconstruct a three-dimensional scene, give the agent a camera, and let it walk. This is a remarkable line of work. It asks how a flat image might become a coherent world under new viewpoints.

It is not the only kind of movement available to a perceptual system, and it may not be the one that matters most for an archive.

An archive does not need to be turned into one continuous virtual room before something can move through it. A system can move by carrying a measured relation from one locus to another. The path is not a corridor through metres of space. It is a **topological connection**: two places become adjacent when a real relation joins them.

Consider a nested circular pattern in a temple façade and a sequence of arches in a mosque. They are not spatial neighbours. They are separated by geography, history, material, and camera. Yet a geometry organ can measure containment in both. If a structure mapper establishes that the relevant relation survives the crossing, the system has a path from one perceptual locus to another.

```text
temple detail
  -- measured nestedness --> mosque arch
```

No continuous scene had to be imagined between them. The move is real because the relation is real, not because the world between the two images was reconstructed.

## Candidate is not connection

The distinction becomes sharp when retrieval enters the picture.

An embedding index can search a large corpus cheaply and return visual neighbours. This is peripheral vision: a retina. It answers a deliberately weak question—*what might be worth looking at next?* Its outputs are candidates, not relations.

That weakness is a virtue. A candidate can be wrong without corrupting memory. In fact, a good movement system must refuse many high-scoring candidates. A bright sky, a waterway, a thin tower, or a hair bun may resemble a source region in an embedding space while failing the actual relation being tested. Similarity is a direction for attention; it is not a reason to move.

The foveal part of the system makes the expensive decision. It calls the relevant organ, compares the structural evidence, and either grounds the relation or refuses it. The result is a two-speed economy:

```text
retina: propose broadly and cheaply
fovea: measure narrowly and carefully
graph: remember only the survivors
```

The ranking may disagree with the verdict. That disagreement is not a bug. It is proof that the system has not mistaken retrieval for intelligence.

## A map made by paths

Each grounded crossing can be remembered as a movement edge. Several such edges can support an axis: nestedness, perhaps, or chromatic recession, or a relation not yet named. The axis is not a theme imposed on the archive from above. It is a reusable dimension discovered from successful paths.

Over time, the archive becomes a topology. Some edges strengthen when measurements recur. Some fade if no evidence returns to them. Some are invalidated when a new measurement contradicts them. The world is living because its shape depends on what continues to hold, not on what was once fluently asserted.

This kind of movement is richer than metaphor but humbler than a universal world model. It does not claim to know what lies behind the wall in a photograph. It claims only that a relation measured here was tested there and survived—or did not survive. The claim can be replayed, inspected, and revised.

## The absence of a path is part of the world

A continuous 3D simulation often treats empty space as something to be filled in. Topological movement does the opposite. If no grounded relation connects two loci, then there is no path yet. The system may search, propose, and ask a curator what is worth testing. It may not narrate a bridge simply because a bridge would make a better story.

This makes the world smaller at first. It also makes it capable of genuine growth. Each new edge changes what can be reached; each new axis changes how the archive can be read; each refusal prevents a false route from becoming infrastructure.

Perceptual movement therefore does not need the smooth illusion of a camera gliding through a generated scene. It needs a world whose adjacencies have been earned. The machine moves not by travelling through the space between images, but by discovering which relations make the distance between them traversable.
